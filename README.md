# YouTube Chapter Detector

A Chrome extension that detects and displays YouTube video chapters in a side panel. Navigate chapters easily, search through them, and save videos for later.

## Demo Video
[Watch the demo video here](Demo%20Video.mkv)

## How to Install

1. Download the extension files from the [releases page](https://github.com/yourusername/YouTube-Chapter-Detector-Chrome-Extension/releases)
2. Open Chrome and go to `chrome://extensions/`
3. Enable **Developer mode** (toggle in the top right corner)
4. Click **Load unpacked**
5. Select the folder containing the extension files
6. The extension will appear in your extensions list

## Features

- Detects YouTube video chapters automatically
- Navigate chapters by clicking on them
- Search through chapters
- Save and manage video history
- Works in side panel or popup mode
